Temat:
Orthodontic Clinic App – aplikacja webowa do zarządzania kliniką ortodontyczną
Opis:
Aplikacja webowa wspierająca obsługę gabinetu ortodontycznego. Umożliwia zarządzanie pacjentami,
lekarzami oraz wizytami. Backend: ASP.NET Core Web API + Entity Framework Core + SQL Server.
Frontend: Vue 3 + TypeScript + Axios (osobna aplikacja SPA). Pełne CRUD dla trzech encji,
przesyłanie i pobieranie plików binarnych (dokumenty pacjenta), konteneryzacja Docker.
Link do pobrania projektu:
https://github.com/if660/Orthodontic_clinic_app
